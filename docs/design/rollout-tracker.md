## 规则
- **盲做模式**：暂无真机，先把功能写完、单测写全，真机项统一记在文末"待真机验证"。
- **AI 部分**：只做功能与界面；能走系统能力的（如系统 TTS）就做；依赖模型的先留缺口（界面 + 桥接接口占位，提示"模型未就绪"）。
- **新依赖**：未获批准的不引，能自写就自写；确需引入的记在"阻塞"里等用户确认。
- **"建议不做"的 25 项**：用户已要求都做。平台做不到的（要 root / ADB）做成最接近的可行替代，并在页面里写明限制；没有合规数据源的留缺口。
- 共用文件（`registry.ts`、`toolIcons.ts`、文档索引）由主会话统一改。

状态符：✅ 已上线｜🔄 本轮进行中｜⏳ 排队｜🚧 阻塞（见备注）｜⚠️ 降级实现
