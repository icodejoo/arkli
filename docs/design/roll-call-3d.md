# 随机点名 3D 滚筒

状态：实现完成待真机核实。

## 已拍板

| 项 | 决定 |
|---|---|
| 依赖 | 引入 three，只在随机点名页动态 `import()`，不进首页包；按需导入以利 tree-shaking |
| 形态 | 多环滚筒：每环约 16 名，环叠成圆柱；名单按几百人设计 |
| 抽取 | 一次只抽 1 人；去掉“一次抽几人”步进器，保留“不重复”开关与重置；旧缓存 `count` 忽略；`drawNames` 多人逻辑不动，固定传 1 |
| 2D | 不再保留舞台；无 WebGL 或“减少动画”时直接弹出结果文字（提示一次），不做动画 |
| 交互 | 只看：开抽只靠底部“开抽”按钮，3D 区不响应拖动、点击 |
| 风格 | 固定暗色舞台卡片，霓虹主色取当前主题色；转动时震动（节流），停下一下重震；不做音效 |
| 选中表现 | 名字从环上弹出、放大发光，其余环渐暗，再加粒子爆开（`Points` 一次绘制，几百个以内） |
| 可读性 | 转动时允许糊；选中名字单独用大字号重绘；其余名字用文字图集，字号随长度自适应，超长截断加省略号 |
| 浮窗 | 沿用 `useFloatPause`：浮起或离开前台时直接跳到已定结果，停 rAF、释放 WebGL 资源，回来只展示结果 |

## 分工
- 结果先由 `drawNames` 定好，3D 只负责表演；动画时长沿用 `ANIM_MS` 量级，各环依次减速停下，最后一环对准选中者。
- 渲染代码放 `web/src/tools/roll-call/` 下独立模块，纯逻辑（环布局、角度计算、图集分配）单测，WebGL 部分只测可注入的部分。

## 已核实信息
- 震动接口：走 `web/src/native/system.ts` 导出的 `vibrate(pattern: number | number[])`，转动中节流短震，停下时重震；无宿主自动退回 `navigator.vibrate`。
- three 依赖与打包体积：引入 `three@0.186.1`（及 `@types/three@0.186.0`），采用页面内动态 `import()` 与按需命名导入；首页入口 chunk 不含 three，构建产物独立 chunk `stage3d-*.js` 原始大小 522.14 KB，`gzip -9` 体积 129.37 KB。
